# MoveYourAss: aplikacja mobilna, plan

**Spec:** `docs/superpowers/specs/2026-11-01-moveyourass-design.md`
(Expo wg decyzji ze spec; Android; build w GitHub Actions, bez EAS).

**Stos [moje decyzje]:** Expo SDK 58, TypeScript, expo-router (z
`Stack.Protected`), TanStack Query, expo-secure-store (JWT),
`@react-native-google-signin/google-signin` (darmowa wersja, stary SDK
Google na Androidzie; owinięta w `src/auth/google.ts`, więc wymienialna),
expo-camera + expo-image-picker, expo-notifications (natywny token FCM),
jest-expo + Testing Library.

## PR-y (każdy osobny branch od `main`, łańcuchowo)

| # | Branch | Zawartość |
|---|--------|-----------|
| M1 | `feat/mobile-scaffold` | szkielet, klient API, sesja, logowanie Google, wybór prywatności, strefa, CI |
| M2 | `feat/mobile-today` | ekran „Dziś”: trening (aparat/galeria, max 5 zdjęć), odpoczynek, choroba, streak, komunikat odpoczynku, historia |
| M3 | `feat/mobile-social` | tablica, wyszukiwarka (kłódka), profil, obserwowanie i prośby, lajki, komentarze |
| M4 | `feat/mobile-settings` | ustawienia (prywatność, próg, powiadomienia), push (token), sprawdzanie wersji, usuwanie konta |
| M5 | `feat/mobile-release` | workflow budujący podpisany APK i publikujący w GitHub Releases |

Nie da się tu sprawdzić aplikacji na urządzeniu: weryfikacja = typecheck,
testy jednostkowe i `expo export` (Metro bundluje). Logowanie Google,
aparat i push wymagają próby na prawdziwym telefonie.
